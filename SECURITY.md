# Security policy

MemoryGraph is local-first, but it can optionally send selected event content to configured projection or enrichment services. Please read the complete [security and privacy guide](docs/SECURITY.md) before enabling those integrations.

When reporting a vulnerability, do not include credentials, private transcripts, database files, or workstation paths in a public issue. Use a private GitHub Security Advisory when the repository enables that feature; otherwise open a minimal issue asking for a private reporting channel.
